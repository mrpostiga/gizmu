# Gizmu

Gizmu is a Gizmondo emulator written in Rust, with a configurable Vulkan interface,
integrated audio and virtual SD storage. It runs ARM games through Windows CE and
GLES high-level emulation.

Gizmu was built from scratch. It is not affiliated with PocketHLE in any way
and does not use PocketHLE source code.

See the [compatibility report](compatibility.md) for tested games and known issues.
